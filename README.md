# Bangla Converter

A simple and fast web tool to convert Bangla text between **Unicode (Avro)** and **Bijoy (SutonnyMJ)** formats.

## ✨ Features

- Unicode → Bijoy conversion
- Bijoy → Unicode conversion
- Copy & paste support
- Fix Text utility
- Character counter
- Responsive design
- Fast client-side processing
- No login required

## 🌐 Live Demo

https://banglaconverter.pages.dev/

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript

## 📌 About

Bangla Converter is built to provide a clean and convenient way to work with Unicode and Bijoy Bangla text directly from the browser.

The tool focuses on simplicity, speed, and a responsive user experience across desktop and mobile devices.
